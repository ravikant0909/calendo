# Security Policy

Calendo handles calendars, bookings and invitee contact details, so security
reports are very welcome.

## Reporting a vulnerability

**Please do not open a public GitHub issue.** Instead, use GitHub's private
reporting: **Security → Report a vulnerability** on this repository.

Include what you found, how to reproduce it, and what data it exposes. You'll get
a reply within a few days. Please give a reasonable amount of time to ship a fix
before disclosing publicly.

## Scope

In scope: this repository and the hosted service at https://calendo.dev.
Out of scope: denial-of-service, spam, social engineering, and findings that need
a compromised device or account.

Please only test against your own accounts and data.
